## 边界

- `report/` 保存阶段性验证和汇报材料。
- `output/` 仍是 CLI 生成并经正式流程发布的知识文档出口。
- 标记为 `pending-review` 或“未审核候选”的材料不得作为已批准团队知识使用。
- 本目录不保存本地实验数据库、模型响应、密钥或 `.knowledge/` 工作区。
