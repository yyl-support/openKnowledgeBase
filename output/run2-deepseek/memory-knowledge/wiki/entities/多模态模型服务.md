# 多模态模型服务

## 定义

由 `config['api']` 的 `base_url`/`api_key` 配置的外部模型服务，兼容 OpenAI API 协议，承载 `model1`/`model2`/`model3` 三个多模态模型。

## 关键属性

| 属性 | 说明 |
| --- | --- |
| `base_url` | 服务地址 |
| `api_key` | 访问凭据 |
| 模型列表 | `config['image_processing']['model1'/'model2'/'model3']`，用于图片内容描述 |

## 访问方式

- [[ImageProcessor]] 通过 `openai.OpenAI(base_url=..., api_key=...)` 创建客户端。
- 调用 `chat.completions.create(...)`，`messages` 同时包含 `text` 与 `image_url` 两种 content 类型，即多模态输入。
- 三个模型按 `model1 → model2 → model3` 顺序故障转移，详见 [[图片标签提取与增强机制]]。

## 关系

- 被 [[ImageProcessor]] 调用。
- 是 [[图片标签提取与增强机制]] 中图片描述生成的模型依赖。
