# 知识上传白名单鉴权模型

## 定义

基于 `user_id` 白名单的简化权限模型（非完整 RBAC 角色体系）：权限判定依据用户身份（user_id）而非角色，仅允许配置 `rbac.knowledge_upload_users` 白名单中的用户执行知识上传操作。

## 意义

为知识上传 API 提供轻量、可配置的访问控制：

- 配置驱动：白名单通过 `config['rbac']['knowledge_upload_users']` 注入，无需硬编码。
- 两级错误契约：未认证返回 401 `TOKEN_MISSING`，已认证但不在白名单返回 403 `ROLE_DENIED`，将「未认证」与「未授权」清晰区分。
- 单一职责：本模型只负责权限判定，用户身份注入由上游认证中间件完成。

## 常见主题

- permission model：以 user_id 白名单替代角色体系，面向特定操作（知识上传）的细粒度授权。
- 认证与鉴权分层：认证（OIDC）负责「你是谁」，本模型负责「能否上传知识」。
- 部署模型：该权限模型是 [[独立 API 服务部署模型]] 下 API 服务的设计主题之一。
