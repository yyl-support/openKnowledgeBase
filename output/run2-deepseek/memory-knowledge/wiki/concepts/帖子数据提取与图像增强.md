# 帖子数据提取与图像增强

## 定义

[[data_processor]] 的 `extract_topic_data(topic_details)` 方法，从 Discourse 话题详情（topic_details）中逐一提取帖子的 id、标题、标签、创建时间、用户问题、最佳答案与回复列表，形成结构化数据供后续落库/落盘使用。

## 提取逻辑

| 字段 | 来源 |
|---|---|
| id | `topic.id` |
| title | `topic.title`（strip 处理） |
| tags | `topic.tags`，统一转为逗号分隔字符串 |
| created_at | `topic.created_at` |
| user_question | `post_stream.posts[0].cooked`，先经 `process_html_content_with_image_links` 处理 |
| best_answer | 第一个 `accepted_answer=true` 帖子的 cooked 内容 |
| replies | 其余帖子的 cooked 内容列表 |
| llm_answer / summary_question | 默认空字符串，供后续流程填充 |

## 图像增强

文本中若包含图像链接，会通过 [[image_processor]] 的 `enhance_text_with_image_descriptions` 补充图像描述：

- `user_question`：以 `"user_question"` 字段名调用
- `best_answer`：以 `"best_answer"` 字段名调用

## 输出

`extracted_data` 为 dict 列表，可交由 `append_to_csv` 追加写入 CSV（replies 以 JSON 序列化，tags 用逗号拼接）。
