# 检索上下文与提示词组装

## 定义

[[data_processor]] 提供的 `format_search_results_for_prompt(retrieval_result, search_results)` 方法，将检索结果与搜索结果组装成可供大模型消费的最终提示词。

## 组装流程

1. 从 `retrieval_result['related_docs']` 中通过 `extract_json_blocks` 提取 JSON 块列表。
2. 若列表长度 ≥ 3，则将前三个元素分别格式化为三段：
   - `-----Entities(KG)-----` — 知识图谱实体
   - `-----Relationships(KG)-----` — 知识图谱关系
   - `-----Document Chunks(DC)-----` — 文档块
3. 若格式不符合预期，则回退使用 `related_docs` 原始值。
4. 将搜索结果使用 `format_search_results_as_json` 序列化后追加到上下文末尾。
5. 将 `history`（默认空字符串）与 `context_data` 填充进 `PROMPT_TEMPLATE.format(...)`。

## 提示词结构示意

```text
-----Entities(KG)-----
```json
...
```
-----Relationships(KG)-----
```json
...
```
-----Document Chunks(DC)-----
```json
...
```
<搜索结果 JSON>
```

## 意义

将知识图谱（KG）检索上下文与实时搜索结果统一编码进提示词，为大模型提供结构化的外部知识来源，属于系统的检索增强生成（RAG）关键环节。
