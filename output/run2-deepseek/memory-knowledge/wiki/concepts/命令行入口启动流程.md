# 命令行入口启动流程

## 定义

`命令行入口启动流程` 是 [[api_main]] 实现的固定启动流水线：参数解析 → 路径注入 → 日志初始化 → 服务委托启动。

## 意义

- 为 [[ForumBot 独立 API 服务]] 提供统一的启动入口
- 将环境准备（Python 路径）、配置获取（CLI 参数）与业务启动（[[standalone_api]]）解耦
- 统一处理中断与失败日志，保证可观测性

## 步骤

1. **路径注入**：将脚本所在目录及 `src` 子目录插入 `sys.path`
2. **参数解析**：解析 `--host`、`--port`、`--config`
3. **日志初始化**：导入 [[logging_config]] 的 `main_logger`
4. **委托启动**：调用 `run_standalone_api(host, port, config_file)`
5. **异常处理**：`KeyboardInterrupt` → 记录"API服务已停止"；异常 → 记录"API服务启动失败"

## 相关实体

- [[api_main]] — 流程实现者

- [[logging_config]] — 日志来源
- [[ForumBot 独立 API 服务]] — 流程启动的服务
