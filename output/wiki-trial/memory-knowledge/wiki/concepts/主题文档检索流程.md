# 定义

主题文档检索流程指 [[ForumClient]] 中 `retrieve_documents_for_topic` 与 `_get_response_data` 两个方法协作完成的具体数据流模式：

1. 从 `topic` 字典中取出 `id`、`title`、`user_question`；
2. 将 `title` 与 `user_question` 拼接为单一查询字符串 `query`；
3. 调用 `_get_response_data(query)`，该方法向 [[Retrieval Service]] 发起两次请求：
   - 主端点请求，获取 `response`（即 `related_docs`）；
   - `/data` 子端点请求，获取完整数据 `data`；
4. 将 `topic_id`、`related_docs`、`data` 组装为结果字典返回；
5. 根据是否检索到文档记录相应日志。

# 重要性

该流程是 [[论坛自动问答/检索处理链路]] 中承担"知识检索"职责的关键环节，体现了典型的 RAG 查询构造模式（拼接上下文 + 用户问题作为 query），并通过双端点调用同时获取简要响应与完整数据，便于后续不同粒度的使用（如展示 vs. 评估分析）。
