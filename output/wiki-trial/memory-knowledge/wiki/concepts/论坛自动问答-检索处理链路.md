# Definition

论坛自动问答/检索处理链路描述了从主题拉取、查询构造、文档检索到自动回复的端到端数据流，核心由 [[ForumClient]] 驱动：

1. 通过 `fetch_all_forum_topics` 拉取主题（委托 [[data_processor]]）
2. 对每个主题调用 `retrieve_documents_for_topic`，拼接标题与用户问题构造查询（见 [[主题文档检索流程]]）
3. 调用 `_get_response_data` 向 [[Retrieval Service]] 检索相关文档，并采集指标（见 [[检索指标采集机制]]）
4. 可选地调用 `search_related_topics` 搜索相关主题（见 [[相关主题搜索与内容清洗]]）
5. 通过 `reply_to_topic` 将结果回复到 [[Forum Posts API]]

# Significance

该链路是论坛自动问答系统的核心业务流程，串联了拉取、检索、搜索、回复四个环节，是理解 [[ForumClient]] 整体职责的主线。

# Note：实验性未接入功能

当前版本存在尚未接入该链路的实验性标记功能——[[ForumClient]] 新增的 `brand_new_capability` 方法（意图为"批量标记主题为已处理"），目前定义位置异常且功能未完成，未被主链路调用，详见 [[ForumClient]] 页面的"异常/实验性代码"小节。
