# 定义

相关主题搜索与内容清洗指 [[ForumClient]] 中 `search_related_topics` 方法所体现的搜索后处理模式：

1. **关键词长度截断**：若关键词超过 `config['search']['max_keyword_length']`，记录警告日志并截断；
2. **调用搜索服务**：向 [[Search Service]] 发起 POST 请求，携带关键词、语言（`zh`）、分页大小等参数；
3. **内容清洗**：对返回记录的 `title` 与 `textContent` 字段，使用正则表达式 `<.*?>` 去除 HTML 标签（由 `_remove_html_tags` 方法实现）；
4. **异常与失败处理**：非 200 状态码或请求异常均记录错误日志并返回空列表。

# 重要性

该模式保障了搜索结果在下游使用（如展示给用户或作为检索上下文）时的可用性与整洁性，避免 HTML 标签污染文本内容，同时通过关键词截断避免超长请求导致的服务端错误。

# 关联实体

- [[ForumClient]] — 实现该模式的类（`search_related_topics`、`_remove_html_tags` 方法）
- [[Search Service]] — 该模式调用的外部系统
