# 定义

检索指标采集机制是指在 [[ForumClient]] 的 `_get_response_data` 方法上应用 `@capture_retrieval_metrics` 装饰器（来自 [[evaluation_hooks]] 模块），以在每次调用 [[Retrieval Service]] 时自动采集检索相关的评估指标。该机制将评估逻辑与业务逻辑解耦，业务代码本身无需感知指标采集的具体实现。

# 重要性

这体现了系统在评估框架（Evaluation Framework）方面的设计决策：将横切关注点（cross-cutting concern，如指标采集）通过装饰器模式与核心检索逻辑分离，便于独立演进评估逻辑而不影响业务代码，也便于对检索质量、耗时等指标进行持续监控。

# 关联实体

- [[evaluation_hooks]] — 提供 `capture_retrieval_metrics` 装饰器的模块
- [[ForumClient]] — 应用该装饰器的类（`_get_response_data` 方法）
- [[主题文档检索流程]] — 被该机制装饰监控的具体流程
- [[Retrieval Service]] — 被监控的调用对象
